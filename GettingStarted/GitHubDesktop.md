# GitHub Desktop

1. GitHub Desktopをインストールし、GitHubアカウントでサインインします。
2. File > Clone repositoryからFUREQ-DEVELOPの対象リポジトリを選びます。
3. Submoduleを含む統合Workspaceは初回clone後にGit Bash/PowerShellで `git submodule update --init --recursive` を実行します。大きなLFS素材の取得前に必要容量を確認してください。
4. ブランチを作成して変更し、Publish branch後にPull Requestを作成します。
